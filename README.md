# daily-ai-resources

Free resources for Daily Ai (@erky027), in plain English.

Structure: one folder per resource, each folder has its own `index.html`.
- `index.html` — hub page, lists all resources. This is what the bio link points to.
- `prompts/index.html` — 50 copy-paste prompts landing page.

Rules:
- Never rename a published folder. Old links must keep working.
- New resource = new folder + one card on the hub page.
- Only built files go in this repo. Source drafts (docx, etc.) stay local / private.
- Deploy: Cloudflare Pages, custom domain `free.erky.cn` (hub) + `prompts.erky.cn` (kept as a shortcut to /prompts/).
